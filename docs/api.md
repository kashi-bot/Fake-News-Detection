# TruthLens AI API Reference
All routes are prefixed with `/api`.
- `POST /api/auth/login` - Authenticate user.
- `POST /api/verify/headline` - Verify a news headline.
- `POST /api/verify/url` - Verify a news URL.
- `POST /api/verify/image` - Verify an image (OCR).
- `GET /api/history` - Get user verification history.
